## 📌 Overview

**DSA Tracker** (internally *Project Ascend*) is an interactive problem-solving workstation designed to transform ad-hoc coding practice into a structured pattern-recognition system. Built for engineers tackling LeetCode, Codeforces, and technical interviews.

---

## ✨ Features

- **🧠 Pattern-Oriented Categorization**: Group problems by foundational algorithmic archetypes (Two Pointers, Sliding Window, Monotonic Stack, Dynamic Programming, Topological Sort, Union-Find).
- **⏳ Spaced Repetition Engine**: Built-in revision intervals that prompt you to revisit tricky problems before concepts fade.
- **📊 Analytics & Velocity Dashboard**: Real-time charts tracking daily solve counts, difficulty ratios (Easy/Medium/Hard), and category mastery.
- **📝 Deep Notes & Complexity Audits**: Integrated Markdown editor for recording edge cases, intuition notes, and Big-O time/space complexity proofs.
- **🔥 Streaks & Consistency Metrics**: Gamified consistency tracking to maintain momentum and problem-solving rhythm.

- **State & Storage**: LocalStorage / IndexedDB persistence & REST API sync

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm / yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/RajatSharma404/DSA-Tracker.git
   cd DSA-Tracker
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000` (or the port specified in terminal).
