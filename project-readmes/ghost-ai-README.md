## 📌 Overview

**Ghost AI** is a sleek, production-ready AI creation workstation engineered on Next.js 16 and React 19. It delivers low-latency prompt engineering, intelligent document and asset synthesis, and rich interactive workflows wrapped in a futuristic cyberpunk glassmorphism interface.

🔗 **Live Deployment**: [https://ghost-ai-omega-ten.vercel.app](https://ghost-ai-omega-ten.vercel.app)

---

## ✨ Features

- **⚡ Real-Time Streaming Inference**: Low-latency token streaming for lightning-fast generative AI interactions.
- **🌌 Cyber Glassmorphism UI**: High-polish dark mode interface built with custom CSS variables, Tailwind tokens, and Framer Motion micro-interactions.
- **🛠️ Multi-Modal Workflow Suites**: Integrated workspace for prompt templates, content generation, code explanations, and structured data outputs.
- **🔒 Client Security & Privacy**: Secure API key management, environment isolation, and client-side sanitization.
- **📱 Responsive & Serverless**: Fully responsive across mobile, tablet, and desktop viewports, deployed globally on Vercel Edge runtime.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.17 or later)
- An AI API key (e.g., Google Gemini API key or OpenAI key)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/RajatSharma404/ghost-ai.git
   cd ghost-ai
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env.local` file in the root directory:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   # NEXT_PUBLIC_APP_URL=http://localhost:3000
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
